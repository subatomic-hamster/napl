# cuas2 (P13): index of the documents

cuas2 is the from-scratch redesign of the cuas-lite counter-UAS foam-ball turret around a Nerf-Rival-style launcher: dual brushless flywheels, a single-pocket plug-valve gate that feeds exactly one ball per FIRE, six printed modules, a relay weapon rail with a hardware supervisor, feed limiter and shot counter, plus a tracking / threat / learning side-programme. Hard rules are unchanged from v1: drones, balloons and hanging targets only, a person in view blocks fire, a human ARMs, geofenced sector, dead-man and timeout, hardware E-stop and key override everything; threat models are generic kinematic test targets at 3-40 m. This index lists merged results only; every number is quoted from the linked file, which states how it was measured.
